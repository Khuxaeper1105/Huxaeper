# Alex Morgan — Freelance Portfolio

A responsive, single-page portfolio for a freelance web developer. It uses plain HTML, CSS, and JavaScript, so it can be deployed directly to GitHub Pages without a build step.

## Customize it

Replace the placeholder content in `index.html`:

- Change **Alex Morgan** to your name or brand.
- Replace `hello@example.com` with your email address.
- Add your real project links and social profiles.
- Update the project names, services, bio, and technology stack.
- Update the page title and description in the `<head>` for SEO.

## Run locally

Open `index.html` in a browser, or use a local server such as:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the root folder, then save. GitHub will provide the published URL.
